# Legacy FSPS parity check

Compares this fork's SSPs with legacy FSPS (Conroy's Fortran, built from source) on identical
data, so that differences reflect code, not inputs. The fork's own regression references are
generated by the fork and only detect change; this check, together with
`tests/test_physics_oracles.f90`, is what anchors the fork to independent results.

```
tools/legacy_parity/run.sh LEGACY_SRC LEGACY_SPS_HOME [OUTDIR]
```

- `LEGACY_SRC`: a legacy `src/` directory whose isochrone layout matches the fork's data tree.
  The fork currently ships the older MIST layout (`isoc_z*.dat`); upstream master has moved to
  `isoc_feh_*_afe_*`, so use a legacy checkout from before that change.
- `LEGACY_SPS_HOME`: a legacy-layout data tree (`SPECTRA/`, `ISOCHRONES/`, ...) whose files are
  byte-identical to the fork's `data/` tree. Check with `diff -rq`.
- Needs gfortran, Python 3 with NumPy, and the fork built in `build/`.

The script copies the legacy source, applies the constant patch below, builds a small driver
(`ssp_dump.f90`) against it, dumps a Chabrier, solar, MIST + MILES SSP grid with
`add_agb_dust_model = 0` from both codes, and runs `compare_legacy.py`, which exits non-zero
if a tolerance is exceeded. It takes about 20 s.

## The constant patch

Legacy FSPS hard-codes `gsig4pi = 1/4.13E10` (`sps_vars.f90`), which sets the stellar radius
used to scale every main-library spectrum (`16 pi^2 R^2`). The exact value with legacy's own
constants is 1/4.0584e10, so legacy spectra are 1.77% too bright relative to the isochrone
luminosities, while masses and L_bol (taken from the isochrones) are unaffected. The fork uses
the exact 1/(4 pi sigma). This is the uniform ~1.7% offset seen against python-fsps; it is not
a data difference. `run.sh` patches legacy to the exact value.

## Tolerances

Measured on MIST + MILES, Chabrier, solar, `add_agb_dust_model = 0` (fsps-bak legacy source,
upstream 82a8735), with tolerances about twice the measured residual:

| Quantity | Ages | Measured | Tolerance |
|---|---|---|---|
| log M, log L_bol | all | 1.2e-8, 5.6e-8 dex | 1e-6 dex |
| Median fork/legacy - 1, 0.37-2.5 um | log t >= 7 | 2.6e-4 | 5e-4 |
| 99th percentile per-pixel, > 912 A | log t >= 7 | 9.8e-4 | 2e-3 |
| Bolometric integral ratio - 1 | log t >= 7 | 1.0e-4 | 3e-4 |
| Median fork/legacy - 1, 0.37-2.5 um | log t < 7 | 4.9e-3 | 1e-2 |
| Maximum per-pixel, > 912 A | log t < 7 | 2.1e-2 | 3e-2 |
| Bolometric integral ratio - 1 | log t < 7 | 2.9e-3 | 5e-3 |

The log t < 7 residuals (largest at log t 6.0-6.65, around 1500 A, 2.7-2.9 um and in the
optical) come from the Wolf-Rayet / hot-star range and are **not yet explained**. Legacy works
in single precision, which accounts for residuals near 1e-4 but not obviously for 0.5%.

With `add_agb_dust_model = 1` (the default), mid/far-IR residuals reach 13-15% at 65 um and the
bolometric ratio 1.1% at log t = 8.65. The circumstellar dust model uses legacy's older
constants (below), on which the wind radius and pulsation period depend non-linearly; this is
the working explanation, not yet verified.

## Intentional differences from legacy FSPS

Comparisons must avoid or neutralize these (`run.sh` uses defaults: sbss = 0, fbhb = 0,
single-age SSPs, standard filters).

| Difference | Effect | Where it shows |
|---|---|---|
| Exact `gsig4pi` (legacy: 1/4.13e10) | Main-library spectra 1.77% fainter than legacy | All spectra; patched out by `run.sh` |
| IAU / CODATA constants (L_sun 3.828e33 vs 3.839e33, R_sun, year, c) | AGB dust optical depth, WR wind radius, rates per year | IR with AGB dust on |
| Double precision throughout (legacy: single) | ~1e-4 relative | Everywhere |
| Remnant turn-off from the native isochrone, not appended blue stragglers | Legacy loses 2-5% of M_* with sbss > 0 | sbss > 0 |
| Blue-straggler ZAMS from main-sequence arrivals | On MIST, legacy places stragglers among M dwarfs (no light); fork on the upper MS (+0.011 dex L_bol at 10 Gyr for sbss = 2) | sbss > 0, MIST |
| Filter transmission clamped before normalization | Legacy is off by up to 0.0043 mag (Bessell M), 0.0013 (SCUBA 850) | Magnitudes |
| BPASS L_bol from the integral of its spectra | Legacy reports log L = 0 at every age | BPASS L_bol |

Fork-only bugs that were fixed on the way (delayed-tau first moment, single-age CSP mass,
ignored IMF limits, Padova horizontal-branch detection, NaN indices on coarse grids) do not
appear in this list: there the fork now agrees with legacy.

## python-fsps

python-fsps is a fixed, unpatched legacy build, so it cannot be used for this check. As a smoke
test, fork/python-fsps spectra for log t >= 7.2 should sit at 0.9827 +- 0.001 (the gsig4pi
ratio), with mass and L_bol agreeing to 1e-3 dex.
